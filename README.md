# open-uwsc

`open-uwsc` は、Windows 自動化ツール「UWSC」の基本的な言語仕様を再現しつつ、現代的な自動化の方向性を試作した実験的プロジェクトです。

## 1. オリジナルからの拡張・追加機能

本プロジェクトでは、オリジナルの UWSC には存在しない、現代的な開発に便利な以下の機能が追加されています。

- **標準入出力サポート**: `STDOUT`, `STDERR`, `STDIN` 関数によるコンソールとの対話。
- **ブラウザ制御 (CDP)**: `BROWSER_OPEN`, `BROWSER_INPUT`, `BROWSER_CLICK`, `BROWSER_CLOSE` 等による Chrome 制御。
- **JSON / HTTP**: `JSON_PARSE`, `JSON_STRINGIFY`, `HTTP_GET` 等のモダンなデータ連携（試作）。
- **外部アプリケーション連携**: LibreOffice 等の操作デモ（アイディアと資料を AI に与え、数分で実装されたもの）。

## 2. AI 駆動による開発と活用

このプロジェクトのコード、および同梱されている多数の UWSC テストスクリプトは、開発者が自らタイピングすることなく、AI への指示のみで生成されています。

- **習得不要の自動化**: UWSC は癖の強い言語ですが、ドキュメントを AI に読み込ませれば、人間が言語自体を詳しく習得しなくても、欲しい機能を自動的に生成・実装させることが可能です。
- **発展の可能性**: このプロジェクトのソースを AI に読み込ませれば、LibreOffice のフルコントロール等、自分が必要な機能を AI に作らせて拡張していくことが十分可能です。

## 3. 注意点

- **実用目的の方へ**: 継続的なメンテナンスや完全な互換性を求めている方には、[UWSCR](https://github.com/stuncloud/UWSCR) をお勧めします。
- **ネイティブ環境の推奨**: 本格的なオートメーション基盤が必要な場合は、Python 等のエコシステムが充実した言語を選択することをお勧めします。
- **プロジェクトスタイル**: AI による高頻度なコード刷新が常態化しているため、一般的な **Pull Request の受け入れや共同開発は行っておりません。** 興味のある方は、自由に **Fork** して独立した形で開発を進めてください。

## 4. 実行方法

```powershell
# ビルド
cargo build

# スクリプトの実行
cargo run --bin open-uwsc -- your_script.uwsc
```

同梱のテストスクリプト群も、AI（Google Antigravity）によって生成されたものです。
